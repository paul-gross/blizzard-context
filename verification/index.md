# Verification

Blizzard's verifiability-matrix hub — the inventory of concrete methods a skill or agent uses to assert a blizzard
change correct. The matrix conforms to the canon concept at `winter-canon:/verifiability-matrix.md`. Read it when
planning how a change will be checked, not only at review — a plan already names its proof, or that the proof mechanism
must be built first. Parent: [../index.md](../index.md).
